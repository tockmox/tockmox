# Third-party software and licenses

Tockmox is Helm charts, an installer and documentation. The platform it
deploys is other people's software, unmodified, pulled from each project's own
registry at install time. Tockmox distributes source and configuration only
... no third-party binary ships in this repository ... so each deployed
component is governed by its own license, between you and that project. This
page is disclosure, not legal advice: the linked upstream license is
authoritative, and if a license matters to your deployment, read it there.

The authoritative list of what a default install pulls is
[`images.txt`](https://github.com/tockmox/tockmox/blob/main/images.txt) at the
repository root, regenerated by `tools/gen-images.sh` whenever the charts
change. The table below groups that list by layer and adds the license and
the caveats worth knowing before you depend on something.

## The caveats, plainly

**The AGPL set: Garage, Grafana, Loki.** Running unmodified AGPL software as
a service on your own infrastructure imposes no obligation on you beyond the
license's own terms for that software; the AGPL's network clause attaches to
*modifying* the software and offering it to others. Tockmox deploys all three
unmodified from upstream images and distributes none of them. If you fork one
of them inside your deployment and expose it to users, that is between you
and the AGPL.

**Open WebUI is not open source software.** Since v0.6.6 it ships under the
"Open WebUI License": BSD-3-Clause plus a clause forbidding removal or
alteration of its branding in deployments above 50 users without an
enterprise license from the project. Tockmox ships it as the reference
console, unmodified, branding intact, and treats it as swappable: every
platform capability terminates at the gateway, the identity provider or the
database, never inside the console. If your deployment will exceed 50 users,
read the [Open WebUI license](https://docs.openwebui.com/license/) before
relying on it; the obligation is yours, not Tockmox's, and Tockmox cannot
waive it.

**Redis 7.4 is not open source software either.** The console's websocket
state store is the `redis:7.4` image, dual-licensed RSALv2 / SSPLv1 ...
source-available, OSI-rejected. It arrives as the Open WebUI chart's default
and is used as a plain cache with no Redis-specific modules. Two clean exits
exist if the license matters to you: [Valkey](https://valkey.io/) (BSD-3, the
Linux Foundation fork, drop-in at this usage level) via the chart's image
override, or Redis 8.x, which added AGPL-3.0 as an option. Replacing the
default is on the roadmap; today this row is the honest state.

**The open-core pair: Authentik and LiteLLM.** Both are MIT at the core with
an `enterprise/` directory under a separate commercial license, shipped
inside the same image and gated on license keys. Tockmox enables no
enterprise feature of either. If you buy a license from either project and
switch features on, nothing in Tockmox prevents it; nothing in Tockmox
requires it either.

**Icons and marks.** Vendored third-party application icons and their sources
are itemised in [`NOTICE`](https://github.com/tockmox/tockmox/blob/main/NOTICE)
at the repository root. Tockmox's own marks are covered by
[`TRADEMARKS.md`](https://github.com/tockmox/tockmox/blob/main/TRADEMARKS.md).
