# Deployment

These pages take you from "what do I need" to a running install, and then to the day you move it to a newer release. Read them in the order below the first time. After that, jump to the page you need: [upgrading](upgrade.md) and [air-gapped installs](airgap.md) are the two you come back to.

**Which preparation path is yours.** Start at [prerequisites](prerequisites.md). It sends you to [a fresh cluster](fresh-install.md) if you are building one for Tockmox, or to [a cluster you already have](existing-cluster.md) if not. Both paths converge on [install](install.md).
