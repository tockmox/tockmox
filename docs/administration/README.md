# Administration

These pages are for the person who owns the cluster after it is up: what you can change, what is a promise and what is not, and how to add or remove an application without losing your changes at the next upgrade. Read the first four before touching a value. The rest are reference for when you meet the topic.

Pages marked experimental in their description are not covered by the stable values contract.
