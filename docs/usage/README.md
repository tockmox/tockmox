# Using Tockmox

The path from a healthy install to actually using the platform. Two kinds of reader land here, and the pages say which one they are for:

- **The operator, once.** [Sign in for the first time](getting-started.md) is the person who installed Tockmox, working with `kubectl` and the Authentik admin interface to make the first accounts. It is not a page for the people you later give accounts to.
- **Then, using it.** [The AI plane](ai-plane.md) is what the chat console and the model gateway are, where a request goes, and how the operator points them at models. [What you get](what-you-get.md) says what is and is not built, for anyone deciding what to rely on.
