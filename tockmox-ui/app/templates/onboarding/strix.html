Ryzen AI Max machines share system memory with the GPU. Linux only gives the GPU a slice of it unless you raise the limit.

  1. Give the GPU most of the memory

    sudo sed -i 's/GRUB_CMDLINE_LINUX_DEFAULT="/&amdgpu.gttsize=110000 ttm.pages_limit=28160000 /' /etc/default/grub
sudo update-grub && sudo reboot
cat /sys/class/drm/card*/device/mem_info_gtt_total

    Set the firmware's dedicated GPU memory to its minimum (often 512 MB) as well. The figures are for 128 GB machines; scale them for less.
