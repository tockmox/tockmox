Every command runs on the Mac, in Terminal, as an administrator. The engine runs as a LaunchDaemon so it starts at boot without anyone signed in.

  1. Keep the Mac awake and recover from power loss

    sudo pmset -a sleep 0 disksleep 0 autorestart 1 womp 1 standby 0 autopoweroff 0

  2. Install Homebrew, if it is not there

    command -v brew || /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
    3. {% if engine == "ollama" %}

  3. Install Ollama and run it as a LaunchDaemon on the network

    Use the Homebrew daemon, not the Ollama app: two copies fighting over port {{ port }} is a known trap.

    brew install ollama
sudo tee /Library/LaunchDaemons/com.tockmox.ollama.plist >/dev/null <<PLIST
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>com.tockmox.ollama</string>
  <key>UserName</key><string>$(whoami)</string>
  <key>ProgramArguments</key><array><string>$(brew --prefix)/bin/ollama</string><string>serve</string></array>
  <key>EnvironmentVariables</key><dict>
    <key>OLLAMA_HOST</key><string>0.0.0.0:{{ port }}</string>
    <key>OLLAMA_KEEP_ALIVE</key><string>-1</string>
    <key>HOME</key><string>$HOME</string>
  </dict>
  <key>RunAtLoad</key><true/><key>KeepAlive</key><true/>
</dict></plist>
PLIST
sudo launchctl bootstrap system /Library/LaunchDaemons/com.tockmox.ollama.plist
    4. {% elif engine == "mlx-lm" %}

  4. Install mlx-lm in its own environment

    brew install python@3.12
$(brew --prefix)/bin/python3.12 -m venv "$HOME/.venvs/mlx-lm"
"$HOME/.venvs/mlx-lm/bin/pip" install mlx-lm

    Pin the version once it works (pip install mlx-lm==X.Y.Z); upgrades change behaviour.

  5. Serve one model as a LaunchDaemon

    One server per model and port. To serve a second model, repeat with another label and port (8082, 8083, ...).

    MODEL={{ model or "mlx-community/MODEL" }}
sudo tee /Library/LaunchDaemons/com.tockmox.mlx-lm-{{ port }}.plist >/dev/null <<PLIST
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>com.tockmox.mlx-lm-{{ port }}</string>
  <key>UserName</key><string>$(whoami)</string>
  <key>ProgramArguments</key><array>
    <string>$HOME/.venvs/mlx-lm/bin/mlx_lm.server</string>
    <string>--host</string><string>0.0.0.0</string><string>--port</string><string>{{ port }}</string>
    <string>--model</string><string>$MODEL</string>
  </array>
  <key>EnvironmentVariables</key><dict><key>HOME</key><string>$HOME</string></dict>
  <key>RunAtLoad</key><true/><key>KeepAlive</key><true/>
</dict></plist>
PLIST
sudo launchctl bootstrap system /Library/LaunchDaemons/com.tockmox.mlx-lm-{{ port }}.plist

    7. {% endif %}

  7. Let only the gateway in (pf)

    macOS's packet filter, in its own anchor so a macOS update does not erase it. {{ eng.note }}

    sudo tee /etc/pf.anchors/com.tockmox.models >/dev/null <<PF
table <gateway> const { {{ src|join(", ") }} }
pass in quick on lo0 proto tcp to any port {{ port }}
pass in quick proto tcp from <gateway> to any port {{ port }}
block return in quick proto tcp from any to any port {{ port }}
PF
grep -q com.tockmox.models /etc/pf.conf || printf 'anchor "com.tockmox.models"\nload anchor "com.tockmox.models" from "/etc/pf.anchors/com.tockmox.models"\n' | sudo tee -a /etc/pf.conf
sudo pfctl -E -f /etc/pf.conf

    A macOS update can rewrite /etc/pf.conf; re-run the last two lines after one, or manage them with your configuration tool.

  8. Check it locally

    {% if engine == "ollama" %}curl -s http://127.0.0.1:{{ port }}/api/version{% else %}curl -s http://127.0.0.1:{{ port }}/v1/models{% endif %}

  9. Export metrics (recommended)

    node_exporter for the host and macmon for unified-memory use, GPU power and temperature. This page reads both through Prometheus; macmon is what lets it show memory pressure.

    brew install node_exporter macmon
brew services start node_exporter
macmon serve --port 9101 &

    Run macmon as a LaunchDaemon for real use, in the same shape as above. Add ports 9100 and 9101 to the pf anchor's gateway rule if Prometheus scrapes from the cluster.
