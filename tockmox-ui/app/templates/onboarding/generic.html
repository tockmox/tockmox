Any server works if it meets these four conditions. Tockmox only needs to reach it over HTTP.

  1. It answers GET /v1/models

    The OpenAI-compatible model list. Chat, embeddings and rerank routes go through the gateway's OpenAI and Infinity providers.

  2. It listens on the node's network address

    Not only on 127.0.0.1.

  3. It requires a token, or only the gateway can reach it

    Ideally both: a bearer token the gateway holds as a Secret, and a firewall rule admitting only {{ (sources or ["the gateway's source addresses"])|join(", ") }}.

  4. Its host exports metrics

    node_exporter at least, so this page can show whether the host is up. Without it the node reads Unknown.
