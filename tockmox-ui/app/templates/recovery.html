If something is down

This page needs no sign-in and shows no data, so it works when sign-in does not. The Tockmox UI is never the only way to see your platform: everything it shows comes from tools you can reach directly.

You cannot sign in

Sign-in goes through Authentik. If you were already signed in, your session keeps working until it expires. If Authentik itself is down, check it from a workstation with cluster access:

kubectl -n tockmox-authentik get pods
kubectl -n {{ argocd_ns }} get applications | grep -i identity

See what the UI would show, without it

Command-line equivalents for each part of the UI
In the UICommand
Layers, sync and health, versionkubectl -n {{ argocd_ns }} get applications -o custom-columns='LAYER:.metadata.name,REVISION:.spec.sources[0].targetRevision,SYNC:.status.sync.status,HEALTH:.status.health.status'
Nodeskubectl get nodes
Alerts firingkubectl -n tockmox-monitoring get svc | grep -i alertmanager, then kubectl -n tockmox-monitoring port-forward svc/NAME 9093 and open http://localhost:9093
Pods not runningkubectl get pods -A | grep -Ev 'Running|Completed'

The Tockmox UI itself is down

kubectl -n tockmox-ui get pods
kubectl -n tockmox-ui logs deploy/tockmox-ui --tail=50

Every console keeps working on its own address while the UI is down. The short links (like /grafana) do not.
